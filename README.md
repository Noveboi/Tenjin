# Tenjin

A simple learning management system (LMS) with a communication-first focus.

## Project Structure

Tenjin is a classic web-based system that uses different technologies for its [back-end](backend/README.md) and [front-end](frontend/README.md).
The core directories/files of the project are:

- [**backend/**](backend): Contains everything tied to the back-end project
- [**frontend/**](frontend): Contains everything tied to the front-end project
- [**CHANGELOG.md**](CHANGELOG.md): Everything of note is marked here, this acts like a journal for the development progress of Tenjin
