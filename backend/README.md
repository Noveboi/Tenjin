# Tenjin Back-End

The `backend` folder contains everything related to the back-end of Tenjin.

## Info

Tenjin's back-end is a web-based HTTP API built with [Go](https://go.dev/). It is designed to satisfy two clients:

1. The front-end application, which provides the web-based graphical user interface and is the primary way of interacting with the LMS
2. Developers that are building their own software, who would like to integrate it with Tenjin to some extent.
